# Profile and security

The profile and security pages are account sections. Open them from the **profile menu** in the header or from **Settings → Profile / Security**.

## Profile

The profile page shows:

- Your personal information: name, email, phone, identity, RTN, and address.
- Account activity: last access, confirmation date, and member since.
- Your role and status.

Use **Edit profile** to change your own details. Admins can also open another user's profile from **Users** and edit it there. Sellers can only edit their own profile and cannot change roles.

If an admin opens a customer profile, the page also shows the credit score and a link to the customer's financing summary. The user drawer offers the balance statement PDF.

## Security

The **Security** section manages your password:

- **Password** — enter a new password and confirmation. The form checks strength and requires at least 6 characters with a mix of letters and numbers.
- **Must change password** — if you sign in with a temporary password, a banner asks you to change it before continuing.
- **Two-step verification** — shown as **Coming soon** and disabled; the current API does not expose it.
- **Active sessions** — shown as **Not available yet** and disabled; session management is not available in the current API.
- **Security recommendations** — use a unique password, at least 8 characters, and avoid common patterns or personal information.

When an admin edits another user, the same security form can set a new password for that user without knowing the old one. When you change your own password, the current password is required.
