# General settings and branding

> **Admin only.** Sellers cannot open the Settings area.

## General settings

The **General** section controls deployment-wide options:

- **Support WhatsApp** — the number customers see for help.
- **Support email** — the address customers see for help.
- **Reservation hold hours** — how long a reservation holds a lot before it is released. The default is `48` hours; valid values are `1` to `720`.

Changing the hold affects new holds; it does not change the amount of time already elapsed on existing reservations.

## Branding

The **Brand identity** section controls the application name and logos:

- **Application name** — used in the browser tab and in the sign-in screens.
- **Light logo** and optional **dark logo** — shown in the sidebar and auth screens.

Recommended logo size is `640 × 160` (4:1), minimum `320 × 80`, maximum file size `2 MB`, in PNG, JPEG, or WebP. A transparent, horizontal wordmark works best. Without a custom logo, the app uses its bundled logo.

## Why it matters

These settings are shared by everyone who uses the deployment. Review them before going live and after a rebrand.
