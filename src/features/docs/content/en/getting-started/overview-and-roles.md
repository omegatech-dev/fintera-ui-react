# System overview and roles

Fintera is a back office for real-estate financing. It tracks **projects**, their **lots**, the **contracts** that sell those lots, and the **payments** that collect the money.

## Admin menu

Admins see these entries in the sidebar, in this order:

| Entry | What it is for |
| --- | --- |
| **Dashboard** | Daily summary, collections, approvals and recent activity. |
| **Payments** | Review receipts, approve or reject payments, and follow overdue installments. |
| **Commissions** | Commission totals, payouts and project commission rates. |
| **Contracts** | List of sales, reservations and their statuses. |
| **Projects** | Developments, lot inventory, media and payment instructions. |
| **Users** | Staff and customer accounts. |
| **Analytics** | KPIs, trends, lot availability, overdue balance and exports. |
| **Audits** | System change log with model and action filters. |
| **Guide** | This guide. |
| **Settings** | Organization settings, brand identity, profile, security and terms. |

## Seller workspace

Sellers get a focused workspace instead of the full admin menu:

| Entry | What it is for |
| --- | --- |
| **My day** | Sales summary, estimated commission and recent activity. |
| **My clients** | Clients that come from the seller's contracts. |
| **Collections** | Contracts with a balance and the receipt upload flow. |
| **Commissions** | The seller's commissions for the current month, read-only. |
| **Documents** | Contracts with documents available. |

The seller sidebar does **not** show Contracts, Projects, Guide or Settings. When the seller needs a contract, the workspace links directly to its detail in read-only mode. **New reservation** opens Projects so the seller can pick an available lot and start the reservation.

On phones, the bottom bar still offers **Home**, **Contracts**, **Payments**, **Projects** and **More**.

## Roles

- **Admin** — full access: approvals, project and lot management, users, commissions payouts, analytics, audits and settings.
- **Seller** — works the sales pipeline: creates reservations, follows their clients, registers collection receipts, and reads their own commissions. Sellers cannot approve or reject contracts or payments, pay commissions, change commission rates, manage users or settings, or open Analytics and Audits.
- **Customer** — uses the customer portal, not this back office.

> Your role controls which articles appear in this guide. Sellers only see articles that apply to their workspace.
