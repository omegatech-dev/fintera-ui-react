# Creating and managing projects and lots

> **Admin only.** Sellers can view projects and lots but cannot create, edit, delete, or publish them.

## Create a project

1. Open **Projects** and select **New Project**.
2. Fill in the name, description, address, city, code, project type, and the number of lots.
3. Set the **measurement unit**, **price per square unit**, **interest rate**, and the **commission rates** for direct, bank, and cash financing.
4. Set the delivery date and save.

The project code and public identifier are generated for you.

## Manage lots

- Create lots individually or in bulk according to the project's lot count.
- Set each lot's dimensions, area, price, and address.
- Use an **override area** or **override price** only when the calculated value is not what you want.
- Add boundary descriptions when the project needs them.

## Publish and unpublish

Publishing exposes the project in the customer portal. Unpublishing hides it without deleting data. Publishing is admin-only.

## Import and media

- **Import CSV** creates or updates projects in bulk.
- Project **photos** and **drawings** are managed from the project media section.
- **Payment instructions** shown to customers are configured per project.

## Deleting

Deleting a project is permanent and admin-only. A project that already has active contracts should not be deleted; cancel or resolve those contracts first.
