# Projects list and project detail

## Projects list

Open **Projects** to see every project as a card. Each card shows the cover image, name, status, location, lot counts, price per unit, and a link to the public portal when the project is published.

Use the toolbar to narrow the list:

- **Search** by name or code. A full project GUID also works; searches shorter than three characters are ignored.
- **All**, **Published**, and **Drafts** chips filter by visibility.
- **Sort** by name, creation date, or no sorting.
- The list is paginated and shows the page range and total project count.

Admins also see **New Project** and **Import CSV**. Sellers do not see those buttons.

## Project detail

Select a project to open its detail page. The header shows the project name, status chip, location, and the **View lots** action. Admins also see **Edit Project**.

A summary strip shows the code, location, delivery date, and lot count with available lots.

The project detail has five tabs:

### Overview

- Description and project metadata.
- **Availability** bar with available, reserved, and financed lots.
- **Recent activity** from the audit log.
- **Project info** with code, type, measurement unit, price per unit, currency, status, and interest rate.
- **Documents** card with plans, photo count, and a shortcut to the Media tab.

### Lots

Shows the most recently updated lots with status, dimensions, area, price, and the customer who reserved them. Use **View lots** to open the complete lot list with search, status chips, and sorting.

### Media

Admins manage project plans and photos here. Sellers can view the same media but cannot upload or delete it.

### Payment instructions

Lists the bank accounts shown to customers. Admins can open **Manage instructions** to add, edit, or remove accounts; sellers only see the configured accounts.

### Activity

The project's audit events, with the actor and date. Select the tab again after an action to refresh the list.
