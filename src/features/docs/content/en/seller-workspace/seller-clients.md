# My clients

**My clients** groups the customers that come from the seller's contracts. It is not the admin Users page: the data is limited to the seller's own portfolio.

## Summary cards

- **Active clients** — clients with at least one active contract.
- **With pending payment** — clients whose active contracts still have a balance.
- **Total portfolio** — the financed amount across the seller's clients.

## Tabs and search

The workspace tabs are **My clients**, **Collections**, **Commissions**, and **Documents**. Each tab shows its count.

Use the search box to filter by client name, phone, or identity. The list is paginated and shows how many clients are visible.

## Table

Each row shows:

- Client name and identity.
- Phone.
- Contracts, as **active / total**.
- Total amount.
- Last update date.

On mobile the same data appears as cards with a **Payment pending** or **Up to date** chip.
