# Perfil y seguridad

Las páginas de perfil y seguridad son secciones de cuenta. Ábrelas desde el **menú de perfil** del encabezado o desde **Configuración → Perfil / Seguridad**.

## Perfil

La página de perfil muestra:

- Tu información personal: nombre, correo, teléfono, identidad, RTN y dirección.
- Actividad de la cuenta: último acceso, fecha de confirmación y miembro desde.
- Tu rol y estado.

Usa **Editar perfil** para cambiar tus propios datos. Los administradores también pueden abrir el perfil de otro usuario desde **Usuarios** y editarlo allí. Los vendedores solo pueden editar su propio perfil y no pueden cambiar roles.

Si un administrador abre el perfil de un cliente, la página también muestra el puntaje de crédito y un enlace al resumen financiero del cliente. El panel del usuario ofrece el PDF del estado de cuenta.

## Seguridad

La sección **Seguridad** gestiona tu contraseña:

- **Contraseña** — ingresa una nueva contraseña y su confirmación. El formulario valida la fortaleza y exige al menos 6 caracteres con una combinación de letras y números.
- **Debe cambiar la contraseña** — si inicias sesión con una contraseña temporal, un aviso te pide cambiarla antes de continuar.
- **Verificación en dos pasos** — se muestra como **Próximamente** y deshabilitada; la API actual no la expone.
- **Sesiones activas** — se muestra como **Aún no disponible** y deshabilitada; la gestión de sesiones no está disponible en la API actual.
- **Recomendaciones de seguridad** — usa una contraseña única, de al menos 8 caracteres, y evita patrones comunes o información personal.

Cuando un administrador edita a otro usuario, el mismo formulario de seguridad puede establecer una nueva contraseña sin conocer la anterior. Cuando cambias tu propia contraseña, se requiere la contraseña actual.
