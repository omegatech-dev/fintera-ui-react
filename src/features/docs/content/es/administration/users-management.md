# Usuarios y roles

El área de **Usuarios** lista a las personas que pueden iniciar sesión en el sistema administrativo.

## Roles

- **Administrador** — acceso total, incluyendo aprobaciones, administración de proyectos, configuración y usuarios.
- **Vendedor** — trabaja el embudo de ventas; no puede aprobar pagos o contratos ni cambiar la configuración.
- **Usuario** — cuenta de cliente. Los clientes usan el portal de clientes.

## Qué puede hacer cada rol aquí

- **Vendedores** pueden ver la lista de usuarios y crear usuarios.
- **Administradores** también pueden eliminar, activar/desactivar y restaurar usuarios.

## Estado del usuario

| Estado | Significado |
| --- | --- |
| Activo | Puede iniciar sesión. |
| Inactivo | No puede iniciar sesión. |
| Suspendido | Bloqueado, por ejemplo tras intentos fallidos repetidos. |

## Requisitos de contraseña

Al crear un usuario, la contraseña debe tener al menos **8 caracteres**, una letra **mayúscula**, una **minúscula**, un **número** y un **carácter especial**.

## Buenas prácticas

- Usa el rol **vendedor** para el personal de ventas y **administrador** solo para quienes deben aprobar dinero o cambiar la configuración.
- Desactiva un usuario en lugar de eliminarlo cuando puedas necesitar el historial más adelante.
