# Aprobar, rechazar y reabrir contratos

> **Solo administradores.** Estas acciones afectan dinero y disponibilidad de lotes.

## Aprobar

Aprobar un contrato confirma la venta y **genera el calendario de pagos**. Solo se pueden aprobar contratos en estado **pendiente**, **enviado** o **rechazado**.

Antes de aprobar, confirma:

- que el cliente y el lote sean correctos,
- que los montos de reserva y pago inicial coincidan con lo acordado,
- que el tipo de financiamiento y el plazo de pago sean correctos,
- que, para banco o efectivo, la fecha máxima de pago esté definida.

## Rechazar

Rechazar requiere un motivo. Se notifica al cliente y el lote vuelve a **disponible**. Un contrato rechazado se puede corregir y enviar de nuevo, o cancelar.

## Cancelar

Cancelar detiene la venta antes de la aprobación. Igual que el rechazo, libera el lote. Usa la cancelación cuando el cliente desiste.

## Reabrir

Un contrato **cerrado** se puede reabrir. Vuelve a **aprobado** y los pagos pueden continuar. Reabre solo cuando el cierre fue un error o se necesita una devolución o reversión.

## Eliminar un contrato rechazado

Un contrato rechazado se puede eliminar para que el lote se pueda reservar de nuevo. Es distinto de cancelar: eliminar borra el registro.
