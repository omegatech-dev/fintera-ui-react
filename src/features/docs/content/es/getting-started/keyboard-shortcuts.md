# Atajos de teclado

Los atajos usan un acorde: pulsa **g** para navegar o **n** para crear, y luego la tecla indicada. La segunda tecla debe pulsarse en un plazo de aproximadamente 1,2 segundos; si no, el acorde expira y no ocurre nada.

Pulsa **?** en cualquier momento para abrir la lista de atajos de tu rol. Ciérrala con **Escape**.

## Cuándo se pausan los atajos

Los atajos nunca interrumpen la escritura. Se ignoran cuando el foco está en un campo de texto, un área de texto, un selector o cualquier campo editable, y cuando mantienes **Ctrl**, **Cmd** o **Alt**. Tampoco se activan mientras hay otro diálogo abierto.

Pasa el cursor o enfoca una entrada de la barra lateral para ver su atajo junto a la etiqueta.
