# Descripción general y roles

Fintera es un sistema administrativo para el financiamiento de bienes raíces. Administra **proyectos**, sus **lotes**, los **contratos** que venden esos lotes y el **calendario de pagos** que cobra el dinero.

## Áreas principales

| Área | Para qué sirve |
| --- | --- |
| Proyectos | Crear y publicar desarrollos. |
| Lotes | Controlar disponibilidad y precio de cada lote. |
| Contratos | Vender o reservar lotes y dar seguimiento a la aprobación. |
| Pagos | Revisar comprobantes y cobrar cuotas. |
| Reportes | Exportar comisiones, ingresos y mora. |
| Configuración | Identidad de marca y opciones generales (solo administradores). |

## Roles

- **Administrador** — acceso total: aprueba contratos y pagos, y administra proyectos, lotes, usuarios, configuración e identidad de marca.
- **Vendedor** — trabaja el embudo de ventas: consulta proyectos y lotes, crea reservas, consulta contratos y pagos, sube comprobantes y lee reportes. No puede aprobar ni rechazar contratos o pagos, ni cambiar la configuración.
- **Cliente** — usa el portal de clientes, no este sistema administrativo.

> Tu rol determina qué artículos aparecen en esta guía. Los vendedores solo ven las operaciones que pueden realizar.
