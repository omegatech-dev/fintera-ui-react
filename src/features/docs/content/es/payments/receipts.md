# Subir y revisar comprobantes de pago

Un **comprobante** es la prueba de pago que se sube para una fila de pago.

## Subir

1. Abre el pago. Los administradores pueden usar **Pagos** o el calendario del contrato; los vendedores usan **Cobros**.
2. Adjunta el comprobante. Los formatos aceptados son **PDF**, **JPG** y **PNG**.
3. Opcionalmente ingresa el **número de autorización** y el **nombre de la cuenta pagadora** para transferencias bancarias.
4. Confirma. El pago pasa de **pendiente** a **enviado**.

Para una **reserva**, subir el comprobante también mueve el contrato de **pendiente** a **enviado** para que un administrador lo revise.

## Revisar

- **Enviado** significa que el comprobante espera la decisión de un administrador.
- **Rechazado** significa que el comprobante no se aceptó; el cliente puede subir uno nuevo (se muestra el motivo del rechazo).
- **Pagado** significa que un administrador lo aprobó y el monto se registró en el libro mayor.
- **En revisión** es la etiqueta que ve el vendedor cuando acaba de subir un comprobante y aún espera aprobación.

## Quién puede hacer qué

- **Vendedores** suben comprobantes desde **Cobros**, ven el estado **En revisión** y abren los documentos del contrato. No pueden aprobar ni rechazar.
- **Administradores** suben, aprueban, rechazan, deshacen y descargan comprobantes. Ver [Aprobar, rechazar y deshacer pagos](/docs/approving-payments).
