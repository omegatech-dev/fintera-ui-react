# Crear y administrar proyectos y lotes

> **Solo administradores.** Los vendedores pueden consultar proyectos y lotes, pero no crearlos, editarlos, eliminarlos ni publicarlos.

## Crear un proyecto

1. Abre **Proyectos** y selecciona **Nuevo proyecto**.
2. Completa el nombre, la descripción, la dirección, la ciudad, el código, el tipo de proyecto y la cantidad de lotes.
3. Define la **unidad de medida**, el **precio por unidad cuadrada**, la **tasa de interés** y las **tasas de comisión** para financiamiento directo, banco y efectivo.
4. Define la fecha de entrega y guarda.

El código del proyecto y el identificador público se generan automáticamente.

## Administrar lotes

- Crea lotes individualmente o en bloque según la cantidad de lotes del proyecto.
- Define las dimensiones, el área, el precio y la dirección de cada lote.
- Usa un **área manual** o un **precio manual** solo cuando el valor calculado no sea el deseado.
- Agrega descripciones de linderos cuando el proyecto lo requiera.

## Publicar y despublicar

Publicar expone el proyecto en el portal de clientes. Despublicar lo oculta sin borrar datos. Publicar es una acción de administrador.

## Importación y multimedia

- **Importar CSV** crea o actualiza proyectos en bloque.
- Las **fotos** y **planos** del proyecto se administran desde la sección de multimedia.
- Las **instrucciones de pago** que ven los clientes se configuran por proyecto.

## Eliminar

Eliminar un proyecto es permanente y solo lo puede hacer un administrador. Un proyecto con contratos activos no debería eliminarse; primero cancela o resuelve esos contratos.
