# Mis clientes

**Mis clientes** agrupa los clientes que provienen de los contratos del vendedor. No es la página de Usuarios del administrador: los datos se limitan a la cartera del vendedor.

## Tarjetas de resumen

- **Clientes activos** — clientes con al menos un contrato activo.
- **Con pago pendiente** — clientes cuyos contratos activos todavía tienen saldo.
- **Cartera total** — el monto financiado entre los clientes del vendedor.

## Pestañas y búsqueda

Las pestañas del espacio de trabajo son **Mis clientes**, **Cobros**, **Comisiones** y **Documentos**. Cada pestaña muestra su conteo.

Usa el buscador para filtrar por nombre del cliente, teléfono o identidad. La lista está paginada y muestra cuántos clientes son visibles.

## Agregar clientes

- **Agregar cliente** abre el formulario de cliente histórico para un cliente y una venta anteriores a tu uso de Fintera. El registro aparece como **Histórico · por validar** hasta que un administrador lo valide.
- **Importar CSV** carga varios clientes históricos a la vez desde una hoja de cálculo.
- Para una venta nueva, crea el cliente dentro del asistente de reserva.

## Tabla

Cada fila muestra:

- Nombre e identidad del cliente.
- Teléfono.
- Contratos, como **activos / total**.
- Monto total.
- Fecha de la última actualización.

En móvil los mismos datos aparecen como tarjetas con un chip **Pago pendiente** o **Al día**.
